# 🛒 Swiggy Instamart Sales Analytics Dashboard

An interactive **Power BI dashboard** built using **Power BI, MySQL, SQL, Power Query and DAX** to analyze Swiggy Instamart sales performance.

## 📊 Key Metrics

- 💰 Total Revenue: ₹6.43M
- 📈 Total Profit: ₹1.11M
- 🛒 Total Orders: 31,189
- 👥 Total Customers: 17,854
- ⭐ Average Rating: 4.01

## 📌 Dashboard Features

- Revenue by City
- Revenue by Category
- Monthly Revenue
- Top 10 Products
- Payment Method Analysis
- Order Status Analysis
- Average Delivery Time
- Interactive Filters
- Reset All Button

## 🛠️ Tools Used

**Power BI | MySQL | SQL | DAX | Power Query | CSV**

## 📁 Dataset

50,000 Instamart order records from 2025.
